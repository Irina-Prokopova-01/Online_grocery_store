# МАГАЗИН ПРОДУКТОВ

## Описание проекта

Данный проект представляет собой веб-приложение магазина продуктов, реализованное с использованием Django и Django Rest Framework. 
Проект включает функционал для управления категориями и подкатегориями товаров, 
а также работу с продуктами и корзиной покупок.

# Функционал

## Функциональные возможности

### Модели данных:

* Product (связь с SubCategory, Category)

* Category

* SubCategory (связь с родительской Category)

* Cart (связь User)

* CartItem (связь с Cart, Product)

* User

### Административная панель

1. Реализовано управление категориями и подкатегориями:

* Создание, редактирование и удаление категорий и подкатегорий товаров.

* Каждая категория и подкатегория имеют:

- Наименование (обязательное поле)

- Slug-имя (обязательное поле)

- Изображение (обязательное поле)

- Подкатегории связаны с родительской категорией.


2. Реализовано управление продуктами:

* Добавление, изменение и удаление продуктов в админке.

* Продукты должны относиться к определенной подкатегории и категории и имеют:

- Наименование (обязательное поле)

- Slug-имя (обязательное поле)

- Изображение в трех размерах (обязательное поле)

- Цена (обязательное поле)

### Эндпоинты API

1. Эндпоинт для просмотра всех категорий с подкатегориями:

* Поддерживает пагинацию.

* Доступен для всех пользователей.

2. Эндпоинт для вывода продуктов:

* Поддерживает пагинацию.

* Каждый продукт в выводе содержит поля: 

- Наименование

- slug

- Категория, 

- Подкатегория, 

- Цена, 

- Список изображений.

* Доступен для всех пользователей(для просмотра).

3. Эндпоинты для работы с корзиной:

* Добавление, изменение (изменение количества) и удаление продукта в корзине.

* Вывод состава корзины с подсчетом количества товаров и суммы стоимости товаров в корзине.

* Полная очистка корзины.

* Доступны только для авторизованных пользователей и только для их корзины.

### Авторизация

Реализована авторизация по токену. 
Только авторизованные пользователи могут выполнять операции с корзиной.

### Установка

1. Клонируйте репозиторий:
   
git clone https://github.com/Irina-Prokopova-01/Online_grocery_store
   

2. Установите необходимые зависимости:
   
для pip: pip install -r requirements.txt
 для poetry: poetry install
   

3. Выполните миграции базы данных:
   
   python manage.py migrate
   

4. Создайте суперпользователя для доступа к админке:
   
   python manage.py createsuperuser (csu)

5. Запуск проекта

 python manage.py runserver

6. Доступ к документации API

 Swagger UI: http://127.0.0.1:8000/swagger/
   

### Использование

* Для доступа к административной панели перейдите по адресу: http://127.0.0.1:8000/admin/

* Для работы с API используйте инструменты, такие как Postman или cURL.

### Примеры запросов к API

1. Получение всех категорий (в том числе с подкатегориями):
   
   GET /catalog/category-list/ 

2. Получение всех продуктов (в том числе с категорией и подкатегорией):
   
   GET /catalog/product-list/

3. Добавление продукта в корзину (требуется авторизация):
   
   POST /cart/cart/
